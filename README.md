# Build a Portfolio
I have built a responsive website that will display images. links and description.

Visit the live portfolio at: [https://Andrew112.github.io/modern_portfolio](https://Andrew112.github.io/modern_portfolio)

This site is automatically deployed to GitHub Pages using GitHub Actions. Any push to the `main` branch will trigger a deployment.
